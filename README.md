### Esteban Flores

Product engineer in Guatemala City. I build software that businesses run on — mobile,
backend, web, and design — and keep it running in production.

**What's live**

- **Sendabox** — white-label logistics platform. 54,206 shipments processed across 9 courier
  companies. NestJS, PostgreSQL, Redis, Vue, Flutter. [sendabox.ai](https://www.sendabox.ai/)
- **Ventura** — local discovery through a geo-ranked video feed, plus a separate app for
  business owners. 10,000+ downloads. Flutter, Firebase.
  [App Store](https://apps.apple.com/gt/app/ventura-descubre-en-video/id6474079043?l=en-GB) ·
  [Google Play](https://play.google.com/store/apps/details?id=app.venturasystems.ventura)
- **Pita Con Nudo** — two-sided marketplace. 4,933 listings, 1,010 completed orders.
  NestJS, PostgreSQL, Supabase, React. [pitaconnudo.com](https://www.pitaconnudo.com/)
- **BYRG** — native iOS game, built solo in Swift and SpriteKit. Live since 2020.
  [App Store](https://apps.apple.com/gt/app/byrg-addictive-reflex-game/id1503103765?l=en-GB)

Most of this code lives in private repositories, which is why the contribution graph is
busier than the repository list.
